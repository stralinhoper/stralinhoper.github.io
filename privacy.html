Privacy Policy

Last updated: November 8, 2026

This policy covers the personal posting tool run by stralinhoper ("the App"). The App is a self-hosted copy of Postiz used only to upload and schedule videos to the operator's own YouTube channel. It is not offered to the public.

YouTube API Services

The App uses YouTube API Services. By using the App, you agree to the YouTube Terms of Service. Google's handling of your data is covered by the Google Privacy Policy.

What data the App accesses

  • Basic YouTube channel information (channel name, ID and profile picture), so the channel can be shown in the App.
  • Permission to upload videos and set their title, description, privacy status and thumbnail.
  • OAuth access and refresh tokens that Google issues when the channel is connected.

How the data is used

The data is used only to upload and schedule the operator's own videos to the operator's own channel. It is not used for advertising, analytics about other people, or any other purpose.

How the data is stored and shared

All data is stored on the operator's own computer, in the App's local database. It is never sold, and it is not shared with any third party except Google, which receives it as part of the normal YouTube API requests.

Deleting data and revoking access

You can remove the App's access at any time from your Google security settings. Disconnecting the channel in the App deletes its stored tokens and channel information. Stored data is otherwise deleted within 30 days of a request.
